# Overdue / /ˌəʊvəˈdjuː/ 早该发生的；迟来的；过期的

## 当前语境

Ioannidis 用 overdue 表达强烈支持——统计审查不仅受欢迎，而且早就该做了（暗示学术界在此问题上行动迟缓）。

Overdue 在此不是「过期未还」（如 overdue book），而是「迟来的/早该发生的」。与 welcome step forward 连用构成双重正面评价。

## 词源与构词

over-(过度/超过) + due（到期/应得）。字面义：超过了应到的时间。

原始画面: 一列火车本该上午 8 点到达，现在下午 2 点才进站——乘客已经等得太久了。

核心意象: 延迟 + 必然性 + 期待已久 = overdue。

## 用法边界

典型搭配: long overdue; an overdue reform/change/apology.

多义词: (1)（时间上）过期的/逾期的 (2)（抽象）早该发生的/姗姗来迟的。考研阅读中(2)更常见。

常见误用: overdue 不等于 late——late 是中性描述，overdue 含「本该更早」的价值判断。

## 深层解释

Overdue 是态度题的高频信号词。当专家说某事 overdue 时，表达的是「支持 + 不满拖延」的复合态度。

## 一语道破

"Overdue means it should have happened yesterday. Overdue 意味着这件事昨天就该发生了。"
