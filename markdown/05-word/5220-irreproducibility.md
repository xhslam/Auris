# Irreproducibility / /ˌɪriːprəˌdjuːsəˈbɪləti/ 不可重复性；（实验结果）无法复现

## 当前语境

irreproducibility 是当代科研诚信危机的核心术语——已发表论文的结果无法被其他研究者按照相同方法复现。

本文 P1 明确指出 irreproducibility 的原因：basic mistakes in data analysis（数据分析中的基础性错误）。这正是 Science 设立 SBoRE 要解决的问题。

## 词源与构词

ir-(不) + re-(再) + pro-(向前) + duc(引导) + -ibility(名词后缀)。即「不能再引导出相同结果的性质」。

原始画面: 两个人按同一份菜谱做菜，却做出完全不同的味道——食谱有问题。

核心意象: 相同输入 + 不同输出 = irreproducibility（系统有 bug）。

## 用法边界

典型搭配: crisis of irreproducibility; contribute to irreproducibility; reproducibility crisis.

反义词: reproducibility（可重复性）——科学研究的黄金标准。

## 深层解释

Irreproducibility 是 2010 年代学术界最头疼的问题之一。Nature、Science 等顶刊多次发文讨论。根本原因包括：p-hacking、样本量过小、统计方法误用等。

本文中 irreproducibility 是全文的逻辑起点——所有措施都围绕解决这个问题展开。

## 一语道破
