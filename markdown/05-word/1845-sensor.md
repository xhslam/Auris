## Sensor  /ˈsɛnsər/  传感器

### 当前语境





**折叠摘要**：默认语境是检测环境变化并把它转成信号的装置。词性线索是noun。

考研英语一 2024 完形填空 Question 17：Sensor types are chosen to complement the different environments they are needed in. 文中传感器按光、声、重量和运动等环境信号选择，强调“感知输入”而非自行决策。

**展开解析**：默认语境是检测环境变化并把它转成信号的装置。词性线索是noun。例如: The sensor detects changes in temperature. 这里 sensor 是机器的感知入口。

### 词源与构词

- **词源/构词**: sense + -or。sense 来自拉丁语 *sentire* “感觉、感知”，-or 表示执行者或装置。
- **原始画面**: 装置像感官一样察觉温度、光、压力或运动。
- **核心意象**: 感知变化 + 转成信号 = 传感器。

### 用法边界

- **典型搭配**: motion sensor; temperature sensor; sensor data。
- **近义词区别**: detector 强调发现某物存在；sensor 强调持续感知并输出信号。
- **常见误用**: sensor 本身不一定做决策，它通常只收集或转换输入。

### 深层解释

Sensor 是现代自动化系统的 **sense organ**。它把物理世界中的温度、光线、压力、位置、速度等变化变成机器能处理的数据。

因此 sensor 常和 actuator, data, network, AI 连在一起。没有 sensor，系统只能执行预设动作；有了 sensor，系统可以根据环境变化响应。

### 一语道破

> "A sensor is where a machine begins to feel the world. Sensor 是机器开始感知世界的地方。"
