# Reading 页面改造建议：对标 aim-read.top

> 目标：把 auris 的英语阅读模块从"能读"升级到"好用的英语精读助手"。
> 对标对象：aim-read.top（Reader · 英语阅读助手）。
> 当前 auris 代码位置：`src/app/reading/page.tsx`、`src/components/reading/reading-workbench.tsx`、`src/features/reading/*`。

---

## 0. 核心模型（已确认）

**不做实时查词（API/AI），改用"书籍预制查词数据 + 阅读端只读本地词库"。**

aim-read 作者的做法：自己维护后台查词库，手动出"书籍 Word 版 + 查词版本"，上线展示。优点：
- **准确性可控**：人工校对过，不会出现实时 AI 查词的胡编/歧义
- **不依赖外部服务**：契合 auris local-first，私有文本不外发
- **正反馈**：制作查词版本逼自己持续读书、整理

auris 采用同款模型，且做两个增强（你已拍板）：

1. **查词版本制作 = AI 生成候选 + 人工审核**：录入时 AI 自动挑词、起草 音标/释义/词根记忆，你再校对修改。又快又保留"自己整理"的把关感。
2. **未收录词 = 可点 + 显示"暂未收录"**：正文所有单词都可点；收录的弹完整词卡，没收录的弹"暂未收录，可一键加入待整理"占位，边读边补词库。

> 由此形成闭环：**读到生词 → 一键加入"待整理" → AI 起草 → 你审核入库 → 这本书查词版本越来越全**。

## 1. 现状差距

auris 阅读页**视觉/工具栏已和 aim-read 高度一致**（暖橙 `#c66f4d`、纸感留白、顶部 进度% / 译文切换 / 导入 / Aa / 明暗、双语分栏、"带你背"词卡）。差距在功能深度：

| 洞 | 现状 | 目标 |
|----|------|------|
| 词库太薄 | `READING_WORD_CHAINS` 只有 5 个硬编码词 | 每本书一份预制查词数据，覆盖该书词汇 |
| 词卡太薄 | 只有 单词+一句释义+一条例句 | 音标/发音/词性/词根词缀/例句/收藏 |
| 只能点 5 个词 | 仅词库内词可点 | 所有词可点；未收录显示"暂未收录" |
| 没有制作流程 | 只能导入 .docx 出纯文本 | 一套"出查词版本"的录入+审核流程 |
| 没有内容库页 | 只渲染单篇阅读器 | Curated Reads 列表（分组/精选/分类/收藏） |
| 进度不真实 | 仅按悬停段落算、不持久 | 滚动跟踪 + 本地持久化 |

## 2. 数据结构设计

### 词条（扩展 `WordChainEntry` → `WordEntry`，`reading-fixtures.ts`）
```ts
type WordStatus = "curated" | "draft" | "pending";
//  curated 已校对入库 / draft AI起草待审 / pending 仅占位待整理

type WordEntry = {
  word: string;
  phonetic?: string;        // 音标 /juːˈtɪləti/
  audioUrl?: string;        // 发音（或运行时用 speechSynthesis）
  partOfSpeech?: string;    // n. / v.
  definition: string;
  examples: string[];
  root?: string;            // 词根
  morphemes?: string[];     // 词缀拆解 ut | ility
  mnemonic?: string;        // 巧记 / "带你背"
  status: WordStatus;
};
```

### 每本书一份查词数据
- 一本书 = `ReadingSource`（双语正文）+ 一份伴随词库 `words: Record<string, WordEntry>`。
- 存储：跟随现有 `reading-source-note.ts` 的本地存储路子（已用 notes vault 存导入源），词库随源一起持久化。本地优先，不引云同步。

## 3. 三大模块的实现思路

### 模块一：阅读端（改动最小，先做）
1. **所有词可点**：`renderEnglishText` 现在只给词库内词包 `<button>`。改成所有英文 token（`normalizeWord` 后非空）都可点。
2. **点击查词分流**：
   - `curated` → 弹完整词卡
   - `draft` → 弹词卡 + "AI 草稿·未校对"标记
   - 不在库 → 弹"暂未收录"占位 + **「加入待整理」按钮**（写入该书 pending 列表）
3. **词卡补全**：`reading-minimal__word-popover` 补 音标行、喇叭发音（`audioUrl` 或 `speechSynthesis`）、词性、例句列表、"收藏到生词本"（复用 `src/components/workspace/wordbook-panel.tsx`）。
4. **划词查短语**：监听阅读区 `mouseup`/`selectionchange`，取 `window.getSelection()` 非空即查。
- 改动面：`reading-workbench.tsx` + `reading-fixtures.ts` + 词卡 UI。风险低。

### 模块二：查词版本制作流程（核心新增）
"出查词版本"流水线（建议独立页面/面板，如 `reading/authoring`）：
1. **导入书籍** → 双语段落（已有 `mammoth` 解析 .docx；中文译文可后续补/AI 起草）。
2. **挑词**：从正文抽候选词 —— 去停用词、去重、按词频/难度排序。
3. **AI 起草**（仅服务端 `src/app/api/`，用 `OPENAI_API_KEY`）：批量为候选词生成 音标/词性/释义/例句/词根记忆 → `status: "draft"`。
4. **人工审核 UI**：草稿列表，逐条 编辑/通过 → `status: "curated"`；可批量。
5. **保存**到该书词库（本地）。阅读端即时读到。
- "待整理"列表（阅读时一键加入的 pending 词）汇入此流程，作为下一批起草输入。
- 改动面：新增录入页 + 一个 AI 起草 API route + 审核组件。

### 模块三：内容库 / Feed 页（让阅读库成立）
- 新增 `reading-library.tsx`：按日期分组的文章卡 + 顶部精选大卡 + 排序 + 分类（文章/书籍/剧集/电影）+ 收藏夹。
- `ReadingSource` 补 `summary`(中文导读)、`publishedAt`(分组日期)、`author`、`isFavorite`。
- 路由：列表 ↔ 阅读器（`reading/[sourceId]`），或单页状态切换。
- 进度跟踪：`IntersectionObserver` 观察段落记 `maxReadOrder`，`progress = maxReadOrder/total`，随源持久化。

## 5. 补充侦察：其他功能盘点（第二轮）

把 aim-read 其余页面也走了一遍，新发现的功能：

### 复习中心（收藏夹 `/favorites`，4 个 Tab）
- **生词本**（该用户 143 个）：卡片网格，每条 = 发音 + 释义(带词性) + 带你背(词根词缀拆分) + 来源文章/收藏次数/日期；有 网格↔列表切换、排序、筛选、批量管理，还有 👁 疑似"遮挡释义自测"模式。
- **词缀本**：词根/词缀单独成库，从阅读词卡的"词根词缀"区一键收藏加入 → 词根是**一等学习对象**。
- **段落批注**（该用户 100 条）：划线段落带 主题标签(判断力/保持耐心) + 日期 + 出处[78]，每条可 翻译/编辑/删除。
- **收藏文章**：文章级收藏。
> auris 已有 `wordbook-panel.tsx` / `sentencebook-panel.tsx`，这套复习中心**迁移成本低、契合度高**。

### 阅读概览 / 首页 dashboard（`/home`）
- 顶部统计：**今日阅读时长、累计阅读词数、连续天数(streak)** —— 习惯养成。
- **每日推送文章**（"今日暂无推送文章"）。
- **继续阅读**：最近文章列表带进度 + ▶ 续读按钮，区分"已看(未完%)"和"已读(100%✓)"。

### 设置（`/settings`）暴露的能力
- 外观：浅色 / 深色 / **系统跟随**。
- 默认显示：英文 / 双语（默认模式可配）。
- **自动高亮**：选中文本后自动打高亮 → 与"段落批注"联动。
- 发音口音：单词查询、段落朗读都可切 **美音 / 英音**，带试听。
- **段落朗读（整段 TTS）**：听力维度功能。
- 快捷键（9 个）。

### 这些功能在改造里的位置（补进优先级）
- **并入第 1 批**：默认显示模式设置、外观加"系统跟随"（极低成本）。
- **并入第 2/3 批**：复习中心三件套（生词本/词缀本/段落批注，复用现有 panel）、自动高亮+划线、阅读统计/streak/继续阅读、段落朗读 TTS（Web `speechSynthesis` 即可，本地零成本）、美音/英音切换。
- **可选差异化**：每日推送（auris 可做"今日精读"推荐）。

## 6. 注意事项（项目约束）
- **本地优先**：词库/进度/收藏优先本地存储，不引云同步依赖。
- **AI 仅在制作端、仅服务端**：起草走 `src/app/api/`（`OPENAI_API_KEY` 不进浏览器）；产出必须经人工审核才标 `curated`。阅读端不做实时 AI 查词。
- **隐私**：AI 起草只发送"单词 + 必要上下文"，避免整篇私有文本外发。
- **工程纪律**：多步骤实现先列计划 + 每步验证点；改完跑 `npm run lint` 与相关 `vitest`。
