# 桌面侧边栏闲置隐藏与紧凑导航

- 原有 `hideStatus` 窗口偏好扩展为「自动隐藏状态栏和侧边栏」。保持存储键和值兼容，关闭时常驻显示。
- 桌面壳在所有页面监听鼠标移动、指针按下、键盘、焦点、滚轮和滚动。静止 3000ms 后隐藏侧栏；Notes 底部状态栏使用相同行为。
- 侧栏以 280ms ease-in-out 透明度过渡；隐藏时保留 52px 结构列，内容不会跳动。隐藏后的导航及子元素关闭指针命中，键盘焦点仍能恢复侧栏。系统减少动态效果时取消动画。
- 删除展开按钮、展开状态、sessionStorage 读写、展开布局和仅供展开使用的阅读子树；阅读主入口和阅读页自身筛选保留。笔记库保留紧凑入口、名称 tooltip、无障碍名称、添加和切换。
- 保留工作区已有的 Review MCP 修改；不修改 Electron 主进程和预加载。

## 最新产品决定：固定直角侧栏（替代上面的侧栏自动隐藏方案）

用户在视觉预览后明确改为「始终显示，取消侧栏自动隐藏」。当前实现以此为准：

- 侧栏占用固定 30px 结构列，贴左边、上下贯通、0 外边距、0 圆角、无浮层阴影；图标及 Logo 居中。页面内容继续从该列右侧开始。
- 删除桌面壳的 idle hook、隐藏属性、透明度过渡及隐藏 CSS；不会随静止隐藏。此前删除的侧栏展开功能保持删除。
- 窗口设置恢复为「自动隐藏状态栏」，只控制 Notes 底部状态栏。
- 网页预览也使用同一结构列，避免预览中侧栏覆盖内容。
- 复核 VMark 同一固定提交的 `src/components/Sidebar/Sidebar.css`：其侧栏为 stretch/flex 布局，本次沿用 Auris 既有 grid 占位实现，无需复制上游代码。
- 更新几何、桌面壳与设置回归：3 个文件、31 项通过；定向 ESLint 与 diff 检查通过。

宽度最终按用户反馈恢复到原来的 30px，侧栏与结构列同宽；保持直角、全高、常驻显示。


### 侧栏背景对比收敛

六种主题的侧栏背景统一采用 70% 页面背景与 30% surface 混合，降低侧栏与正文的明暗差，保留轻微分区。图标、当前入口指示、30px 占位和直角全高几何保持原有契约。


### 主题像素标志

侧栏左上角改为无底板的像素 A 字标，使用应用 accent 与 muted 令牌绘制两档颜色，随六种主题实时更新。SVG 尺寸从 28px 缩小 10% 至 25.2px，保持侧栏居中与 30px 占位。只修改侧栏标志，不涉及系统应用图标。


### Notes 工作区展开恢复

将进入 Notes 的动作改为显式展开，当前 Notes 入口点击只切换展开状态，不再连带重置页面位置；aria-expanded 与实际列表状态绑定。浏览器预览缺少原生换根接口时保留当前笔记库的根导航，桌面端仍使用已有 listRoots / setRoot / pickDirectory。对照固定 VMark Sidebar.tsx 的实时 aria-expanded 与独立 UI 切换职责，未复制 Tauri 工作区状态管理。新增回归覆盖已展开状态下跨路由进入、重复折叠/展开，以及预览当前笔记库导航；15 项通过。


### 工作区列表渐入渐出

Notes 子列表保留挂载，使用 180ms 透明度与 220ms 高度过渡，收起后延迟隐藏以完整播放淡出。关闭状态立即设置 inert 和 aria-hidden，避免不可见工作区仍能聚焦；系统减少动态效果开启时停用过渡。初次进入的展开使用 CSS starting-style，连续点击由 CSS 从当前进度反向，不依赖卸载计时器。
