# Review 左右工作台与摩天轮（2026-09-07）

用户要求保留四格复习统计与优先处理，将首页改为可调整宽度的左右区域，并用底部摇杆切换右侧的今日任务、逾期任务与项目。按用户要求未使用 frontend-design 技能。

## 实现

- `src/components/review/review-page-client.tsx`：今天视图接入左右工作台；左侧保留 2×2 统计、优先复习卡、完成输出确认、全部计划入口，移除原大标题和侧边后续预览。其他视图及知识点编辑、项目创建继续复用既有流程。
- `src/components/review/review-wheel-workspace.tsx`：可拖动/键盘调整的分隔线，默认左侧 45%，范围 35–60%，单独保存布局偏好。摩天轮有三个内容舱，使用既有队列按 today/overdue 分类及真实项目数据；任务打开详情，项目展开其非归档知识点并可打开详情、创建项目。
- `src/components/review/review-wheel-workspace.css`：圆形轨道及保持正向的内容舱，底部右侧摇杆和前后切换按钮。每站 1.2 秒缓动并限速，不自动播放；轨道空白处滚轮也可换组，内容舱内部滚动列表。非活动舱不可交互；遵循减少动画偏好。1000px 以下改为上下布局。
- `tests/component/review/output-review-page.test.tsx`：迁移旧布局断言，新增摇杆访问逾期详情、项目知识点及宽度持久化的行为回归。

## 验证与边界

- Review 页面与排程模型：2 个文件，12 项测试通过；定向 ESLint、`git diff --check` 与最终 `npm run build` 通过。
- Chromium 1440px：使用隔离浏览器中的样例队列核验摇杆切换、详情入口和真实拖动分隔线（45% → 51%）；页面无横向溢出。
- Chromium 480px：无横向溢出，摩天轮与摇杆可滚动到达，四格统计保持 2×2。巡检发现旧媒体查询会改为三列，已增加局部覆盖；为侧轨保留左侧空间。
- 本次不改变排程模型与用户复习数据；今日列表表示当前阶段今天到期的未完成任务，逾期单独展示。轮上每个内容舱代表一个分类，分类内列表可滚动。
- 样例仅写入隔离测试浏览器；验证服务器已关闭。保留工作区已有 Nia 相关改动，未提交或推送。
