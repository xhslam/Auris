# Notes 侧边栏几何对齐：执行轨迹（2026-08-18）

## 目标
使展开态的主导航按钮与收起态保持同一垂直基线、按钮高度与按钮间距；收起态为视觉基准。

## 实测与根因
收起态主按钮为 36px 高、4px 间距。展开态原先将主按钮改为 34px 高、`6px 8px` 内边距，同时将品牌区底部间距由收起态的节奏压缩，导致展开时首页与 Notes 的首行位置上移、后续按钮节奏失配。

## 修复
展开态主按钮统一为 36px 高和 36px 最小高度，保持 4px 导航间距；品牌区使用 36px 内容高度、8px 底部内边距和经浏览器实测校准的 12px 底部间距。该组合使展开态的首页与 Notes 按钮在动画结束后与收起态顶部位置一致。

## 回归验证
- 新增 Playwright 几何回归断言，比较收起/展开态的首页与 Notes：顶部位置、36px 高度以及 4px 间距。
- 在独立源码服务端口执行完整 `desktop-sidebar-hover` 端到端测试：11 项均通过。
- `npm run desktop:build:verify` 通过，包括生产构建、桌面装配、签名、隐私审计和 MCP sidecar 烟雾验证。
